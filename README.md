# School Management System - ডাঃ মুজিব-রুবি মডেল হাই স্কুল

An all-in-one School Management System and Digital Educational Portal built with Next.js 14, React, Tailwind CSS, TypeScript, MongoDB, and Firebase.

## Features
- 🎓 **Student & Teacher Dashboards**: Real-time management, notices, results, and fees tracking.
- 🛡️ **Super Admin Control Center**: Manage users, reset passwords, update settings, live support inbox, and post notices.
- 💬 **Live Support Chat**: Instant direct messaging between students/parents and school management.
- 📜 **Dynamic Notices & News**: Live update system for school announcements, exam routines, and events.
- ⚡ **Firebase & MongoDB Integration**: Secure cloud storage, live updates, and data persistence.

## Tech Stack
- **Framework**: Next.js 14 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS & Lucide Icons
- **Database**: MongoDB & Mongoose
- **Auth & Storage**: Firebase
- **Deployment**: Ready for Vercel

## Local Setup

1. **Install Dependencies**:
   ```bash
   npm install
   ```

2. **Environment Variables**:
   Create `.env.local` in root and configure `MONGODB_URI` and Firebase credentials.

3. **Run Development Server**:
   ```bash
   npm run dev
   ```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
